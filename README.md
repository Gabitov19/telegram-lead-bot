# 🤖 Telegram-бот для бизнеса с Web App (Lead Bot + Mini-CRM)

👉 **[Попробовать Web App в действии](https://gabitov19.github.io/telegram-lead-bot/webapp/)**

Многофункциональный Telegram-бот, который автоматизирует сбор заявок и онлайн-запись клиентов. Включает в себя современное веб-приложение (Mini App) с календарем и выбором услуг, базу данных и мощную админ-панель.

Идеальное решение для малого и среднего бизнеса (салоны красоты, клиники, онлайн-школы, услуги, инфобизнес).

## ✨ Возможности

### 👤 Для клиентов (Пользователей бота)
- **🚀 Web App (Mini App)**: Современная форма онлайн-записи с анимированным дизайном (Glassmorphism), выбором услуги, даты и времени.
- **Сбор заявок**: Бот запрашивает имя и контакт (можно поделиться телефоном в один клик).
- **FAQ (Часто задаваемые вопросы)**: Быстрые ответы на типовые вопросы.
- **Связь с менеджером**: Кнопка прямой ссылки на живого сотрудника.
- **Обратная связь**: Возможность оставить отзыв или пожелание, которое мгновенно пересылается админу.

### 👑 Для администратора (Владельца бизнеса)
- **Визуальная Админ-панель**: Управление ботом через удобные инлайн-кнопки (без необходимости вводить команды).
- **Детальные уведомления**: Все новые заявки приходят в личные сообщения с указанием имени, контакта, выбранной услуги и **даты/времени записи**.
- **База данных SQLite**: Все заявки надежно сохраняются и не теряются при удалении чата. Время создания фиксируется по локальному часовому поясу.
- **📊 Команда `/leads`**: Просмотр последних 10 заявок прямо в Telegram с полной информацией (дата записи и дата создания заявки).
- **📥 Выгрузка в Excel**: Команда `/export` создает файл `.xlsx`, где есть все колонки: ID, Имя, Контакт, Услуга, Дата записи, Время записи и Время создания.
- **📈 Статистика**: Просмотр количества пользователей, всех заявок и заявок за сегодня.
- **📢 Массовая рассылка**: Инструмент для отправки сообщений (акций, новостей) всей базе пользователей.

### 👥 Для команды (Менеджеры)
- **Система ролей**: Владелец может добавлять и удалять менеджеров прямо через кнопки в Админ-панели.
- **Коллективные уведомления**: Все новые заявки автоматически рассылаются владельцу и всем добавленным менеджерам.
- **Безопасность**: Менеджеры не имеют доступа к выгрузке базы или рассылкам (только к заявкам).

## 🛠 Стек технологий
- **Язык**: Python 3.14
- **Фреймворк**: Aiogram 3.x (асинхронный)
- **Web App**: HTML5, CSS3 (Glassmorphism, анимации), Vanilla JavaScript (Telegram WebApp API)
- **База данных**: SQLite (`aiosqlite`)
- **Работа с Excel**: `openpyxl`
- **Безопасность**: `python-dotenv` (токены и ID скрыты в `.env`)
- **Управление зависимостями**: `uv`
