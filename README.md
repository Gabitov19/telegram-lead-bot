# 🤖 Telegram-бот для сбора заявок (Lead Bot)

Готовое решение для бизнеса, которое автоматизирует сбор контактов клиентов и отправляет уведомления администратору прямо в Telegram.

## ✨ Возможности
- **Сбор заявок в 2 шага**: бот запрашивает имя и контакт.
- **Отправка контакта в один клик**: клиенту не нужно вводить номер вручную, он использует нативную кнопку Telegram.
- **Уведомления админу**: все заявки моментально приходят в личные сообщения администратора.
- **Защита от спама**: встроенный антиспам (не чаще 1 заявки в минуту от одного пользователя).
- **Удобная навигация**: постоянная кнопка «Главное меню» и инлайн-кнопки.
- **Безопасность**: конфиденциальные данные (токен бота и ID админа) вынесены в файл `.env`.
- **База данных SQLite**: все заявки надежно сохраняются в БД. История доступна администратору по команде **/leads**.

## 🛠 Стек технологий
- Python 3.14
- Aiogram 3.x (асинхронный фреймворк)
- FSM (Машина состояний) для ведения диалога
- `uv` для управления зависимостями
